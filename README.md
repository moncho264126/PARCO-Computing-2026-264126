# Distributed Sparse Matrix-Vector Multiplication (SpMV)

This repository contains the complete source code, execution scripts, and analysis tools for a scalability study of **Distributed SpMV** using MPI.

The project evaluates the performance trade-offs between **1D Row-wise Partitioning** (using various I/O strategies) and **2D Grid Partitioning** on a high-performance computing cluster.

## Directory Structure

```text
.
├── matrix/          # Input matrices (MTX format) and vectors.
├── python/          # Python scripts for parsing logs and plotting results.
├── results/         # Raw execution logs (.txt) generated by the PBS jobs.
├── sh/              # Helper shell scripts for compilation and execution loops.
├── source/          # C source code (MPI implementations).
├── run_*.pbs        # PBS Pro submission scripts for the cluster.
└── README.md        # This file.

```

## Project Components

### 1. Source Code (`source/`)

The core implementations are written in **C using MPI**:

- **1D Partitioning**  
  Evaluates `MPI_Allgather`-based replication.  
  Supports:
  - Centralized input
  - Concurrent input
  - MPI-IO input

- **2D Grid Partitioning**  
  Uses row/column communicators to minimize communication surface  
  \[
  O(\sqrt{P})
  \]

- **Hybrid (Experimental)**  
  MPI + OpenMP implementation
