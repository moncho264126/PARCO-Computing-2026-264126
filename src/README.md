# Simulation Executables

This folder contains **all the executables required** to run the various simulations for the deliverable.

## Program Information

For **more details about a particular program**, such as its functionality, input/output formats, and execution instructions, you can open the corresponding source file (`.c`) and read the **header comments** at the top. Each header clearly describes:

- Purpose of the program
- Input and output formats
- How to compile and run
- Requirements and dependencies

## Running via Scripts

To automate simulations, there are **`.sh` scripts** located in the `sh/` folder. These scripts call the executables with the correct parameters.
