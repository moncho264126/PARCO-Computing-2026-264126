# Matrices and Vectors Folder

This folder is intended to **store all the matrices and vectors** used for the Sparse Matrix-Vector multiplication simulations.

## Important Notes

- Any **addition or removal of matrices or vectors** in this folder should be reflected in the corresponding `.sh` scripts used for performance or timing measurements.  
- Ensure that the filenames and the order of matrices and vectors in the scripts match the actual files in this folder, to avoid execution errors.  

Keep this folder organized to maintain reproducibility and consistency across all simulations.
